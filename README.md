# Modern To-Do Application

A fully functional, responsive To-Do List application built with Vanilla JavaScript, HTML5, and CSS3. This project demonstrates dynamic DOM manipulation and browser-based data persistence.

## Features

- **Dynamic Task Management:** Add, edit, and delete tasks instantly.
- **Data Persistence:** Uses the Browser's Local Storage to save tasks permanently until cleared.
- **Task Completion:** Click on task text to toggle a "completed" status (strike-through effect).
- **Keyboard Support:** Supports adding tasks by pressing the "Enter" key for better UX.
- **Mobile Responsive:** Optimized for all screen sizes using CSS Flexbox.
- **Global Action:** "Clear All" button to reset the entire list after user confirmation.

## Technologies Used

- **Frontend:** HTML5, CSS3 (Flexbox, Gradients, Transitions)
- **Scripting:** JavaScript (ES6+), Local Storage API, Event Listeners

## How to Setup

1. Clone this repository to your local machine.
2. Open the `index.html` file in any modern web browser.
3. Start managing your tasks!

## Project Structure

- `index.html`: Contains the application structure.
- `style.css`: Contains all visual styling and animations.
- `script.js`: Contains the core logic and local storage management.
